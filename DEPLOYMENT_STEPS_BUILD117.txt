RebataTrack Website Build 117 - Deployment Steps

PURPOSE
- Move public website/Web App links to the new RebataTrack addresses.
- Move public support/contact references to app.rebatatrack@yahoo.com.
- Keep admin authentication compatible with both the legacy and new administrator email during transition.

DEPLOYMENT ORDER
1. In Firebase project rebatify-beta, add `rebatatrack.github.io` to Authentication > Settings > Authorized domains before switching the Admin/Beta Portal site.
2. Deploy RebataTrack Beta Email Worker Build 117.
3. Deploy RebataTrack Production Admin Worker Build 107.
4. Deploy RebataTrack Main Email Worker Build 6.
5. Deploy Website Build 117 to the RebataTrack GitHub Pages repository.
6. Hard-refresh and test Beta Portal and Admin Portal sign-in, Help & Feedback, production administration, support links, privacy/terms, and password reset.

IMPORTANT TRANSITION NOTE
- Gmail remains the SMTP transport/sending account until Yahoo enables an app password.
- Customer replies and public support links use app.rebatatrack@yahoo.com.
- The legacy admin Firebase Auth email is still temporarily accepted to prevent lockout.
